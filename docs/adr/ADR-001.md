ADR-001: Refactoring Existing Codebase Instead of Rewriting From Scratch

Status: accepted

Context: After two months of development, the vision changed (central ontology, assisted deduction, promise "type a name, see everything"). The initial code was written for an outdated vision, but the core abstraction (Entity / Relationship / Property, Record as universal representation, generic engine + external ontology) remains sound.

Decision: We refactor the existing codebase rather than start from zero. Three-column inventory: keep (debug CLI, configs, pre-commit, connectors, repositories, orchestration), create, delete.

Consequences: We preserve energy already invested in healthy components. Git history remains intact. The classic risk (drift between old code and new design) is covered by these ADRs, which fix target contracts.
