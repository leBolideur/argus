ADR-005: The Engine Proposes, Never Assumes Silently

Status: accepted

Context: Historical tension between the v1 motto ("the engine never guesses silently — the user validates, the engine accompanies") and the v2 ambition ("no action required from the user").

Decision: Model "transparent by default, blocking never":

The engine proposes (rules, relationships, SAME_AS) and persists its proposals.
No validation is required to proceed (application by default).
Everything assumed is reviewable and editable afterwards (delete a relationship, edit a rule, rename).
Consequences: The journal of assumptions must be reconstructible: each relationship knows which rule it derives from (rule → relationship chain). Correction is always possible post-hoc, never blocking at import time.
