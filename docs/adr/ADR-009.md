ADR-009: The Validator Judges Populations, Admits Ignorance

Status: accepted

Context: Typing an attribute is an induction on a bag of observed values, not a deduction. Some values are structurally indistinguishable by form alone (Dupont: first name? city? company?).

Decision:

The Validator judges each attribute on its population of values (individual validators + aggregation by majority policy), never a single isolated value.
What no validator recognizes becomes a generic type — explicit admission of ignorance, not rejection or blocking.
Treatment of outlier values within a typed column (per-line exceptions) is decoupled from the typing cycle: values are stored as-is and flagged; the decision is deferred, never blocking.
The Validator's vocabulary is format-agnostic: "named attribute + bag of values", never "column" (isolation test: a flattened JSON with keys user.email must pass unchanged).
Consequences: Typing is always reversible (generic type can be refined later). Adding formats (XLSX, PDF...) only touches the Connector layer.
